# Scope

This Working Group develops the FPSOT diagrams specification.

The specification covers how FPSOT projects draw, publish and translate diagrams: diagrams as code in PlantUML, the choice of notation (the C4 model for architecture, UML for structure and behavior, BPMN for business processes, and data model diagrams generated from LinkML schemas), the content of text alternatives for diagrams, the use of color in diagrams, the rendered SVG files and their names, and diagrams in English and French.

It does not set accessibility rules or values, which the FPSOT accessibility specification sets, nor the names of files in general, which the FPSOT naming specification sets.

Any changes of Scope are not retroactive.
